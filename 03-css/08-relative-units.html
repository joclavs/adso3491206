08-relativ units

Specify a length relative to another length property.

  • Pixel (px)
  • M (em)
  • X (ex)
  • Root M (rem)
  • Viewport Units Horizontal (vh)
  • Viewport Units Vertical (vw)
  • Large Viewport (lvh/lvw)
  • Small Viewport (svh/svw)
  • Dynamic Viewport (dvh/dvw)

Examples

  • px: 15px
  • em: 1.5em
  • rem: 2rem
  • ex: 2.4ex
